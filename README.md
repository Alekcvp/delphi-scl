# Delphi-SCL
Simple Config Language Library.

## Description

This project is developed as a hobby endeavor for fun and learning. It implements an SCL parser, writer, and a basic serializer. The parser operates independently, with no dependencies on JSON or any other third-party libraries. 

## SCL Format Description

See the [SCL Format](SCL%20Format.md) file for details.

## Features

- Memory-efficient design
- No external dependencies
- Written and tested in Delphi 12
- MPL 2.0 licensed
