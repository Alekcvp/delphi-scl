# Документация по модулю SCL.Reader

## Обзор

Модуль `SCL.Reader` реализует парсер документов формата SCL (Simple Config Language) — облегчённого аналога YAML, заимствующего некоторые идеи из TOML. Модуль предоставляет класс `TSCLReader` для чтения SCL-документов из строки, байтового буфера или файла, а также типы для представления ошибок парсинга и вспомогательный класс-хелпер для работы с кодировками.

## Класс `ESCLParsingException`

Исключение, возбуждаемое при ошибках разбора SCL-документа.

### Свойства

| Свойство | Тип | Описание |
|---|---|---|
| `ErrorCode` | `TSCLParsingError` | Код ошибки парсинга |
| `LineIndex` | `Integer` | Номер строки (с 1), где произошла ошибка |
| `CharIndex` | `Integer` | Позиция символа в строке (с 1), где произошла ошибка |

## Класс `TSCLReader`

Основной класс для чтения и разбора SCL-документов.

### Конструктор

```pascal
constructor Create(const LineBreaks: string = sLineBreak);
```
Создаёт экземпляр парсера. Параметр `LineBreaks` задаёт последовательность символов, используемую для завершения строк при формировании текстовых блоков (по умолчанию — системный перевод строки).

### Методы разбора

```pascal
function ParseDocument(const Buffer: RawByteString;
  Document: TSCLDocument = nil;
  Encoding: TEncoding = nil): TSCLDocument; overload;
```
Разбирает SCL-документ из байтового буфера. Если кодировка не указана, она определяется автоматически с помощью `HEncoding.GuessEncoding`. Если `Document` не задан, создаётся новый документ; в противном случае используется переданный (он предварительно очищается при ошибке).

```pascal
function ParseDocument(const Buffer: string;
  Document: TSCLDocument = nil): TSCLDocument; overload;
```
Разбирает SCL-документ из строки. Если `Document` не задан, создаётся новый; при ошибке созданный документ освобождается, а переданный — очищается.

```pascal
function ParseFile(const AFileName: string;
  Document: TSCLDocument = nil;
  Encoding: TEncoding = nil): TSCLDocument;
```
Читает и разбирает SCL-документ из файла. Кодировка определяется автоматически при отсутствии явного указания. Имя файла сохраняется для использования в сообщениях об ошибках.

```pascal
class function ReadFrom(const AFileName: string): TSCLDocument;
```
Удобный статический метод: создаёт экземпляр `TSCLReader`, разбирает файл и возвращает готовый документ, автоматически освобождая парсер.

### Поведение и особенности

- Парсер поддерживает комментарии (`#`), скалярные значения (числа, строки, булевы значения, `null`, `inf`, `nan`, даты и время), двоичные/восьмеричные/шестнадцатеричные литералы, строчные массивы (`[...]`) и таблицы (`{...}`), а также многострочные текстовые блоки (`|` и `>`).
- При возникновении ошибки разбора возбуждается `ESCLParsingException` с указанием файла, строки и позиции символа.
- Максимальный размер читаемого файла ограничен `Word.MaxValue` байт (около 64 КБ); при превышении возбуждается исключение.
- Поддерживается BOM (UTF-8, UTF-16 LE/BE) и автоматическое определение кодировки.
