# Документация по модулю SCL.Writer

## Обзор

Модуль `SCL.Writer` реализует сериализацию (запись) документов SCL (Simple Config Language) в текстовое представление. Модуль предоставляет класс `TSCLWriter`, который преобразует объектную модель `TSCLDocument` обратно в SCL-формат с настраиваемыми отступами, шириной переноса строк и режимами форматирования, а также умеет сохранять результат в файл с заданной кодировкой.

---

## Константа `WRAP_BIAS`

```pascal
const WRAP_BIAS = 8;
```

Задаёт «коридор» (в символах) вокруг целевой ширины переноса, в пределах которого при свёртке строк предпочтение отдаётся пробелу для более естественного разбиения текста.

---

## Класс `ESCLWritingException`

Исключение, возбуждаемое при ошибках записи SCL-документа: недопустимых параметрах форматирования (шаг отступа, ширина переноса), непечатных символах в строках, ошибках доступа к файлу и т.п.

---

## Класс `TSCLWriter`

Основной класс для сериализации SCL-документов.

### Конструктор

```pascal
constructor Create(AIndentStep: Integer = 2; AWrapWidth: Integer = 80);
```

Создаёт экземпляр писателя. Параметры:

- `AIndentStep` — шаг отступа для каждого нового уровня вложенности (допустимый диапазон: 2–8, иначе возбуждается `ESCLWritingException`);
- `AWrapWidth` — целевая ширина переноса строк для свёрнутых (`>`) текстовых блоков (значение должно быть не меньше `MIN_WRAPPED_WIDTH`, иначе возбуждается исключение).

### Свойства

| Свойство | Тип | Описание |
|---|---|---|
| `IndentStep` | `Integer` | Шаг отступа для каждого нового уровня вложенности. Допустимый диапазон: 2–8. При выходе за пределы возбуждается `ESCLWritingException` |
| `LeadArray` | `Boolean` | Если `True`, вложенные в массив контейнеры (массивы/таблицы) пишутся с новой строки; если `False` — с текущей строки после `- ` |
| `SpaceNodes` | `Boolean` | Если `True`, между «сложными» узлами (массивы, таблицы, многострочные текстовые блоки) в таблицах вставляются пустые строки для визуального разделения |
| `WrapWidth` | `Integer` | Глобальная целевая ширина для переноса строк в свёрнутых текстовых блоках. Минимум — `MIN_WRAPPED_WIDTH`; при меньшем значении возбуждается `ESCLWritingException` |

### Методы

```pascal
function WriteDocument(Document: TSCLDocument): string; overload;
```

Сериализует документ в строку в формате SCL. Возвращает готовое текстовое представление. Внутреннее состояние писателя (стек отступов, буфер текста, предыдущий узел) сбрасывается перед записью, поэтому один экземпляр можно переиспользовать для нескольких документов.

```pascal
procedure WriteDocument(const AFileName: string;
  Document: TSCLDocument; Encoding: TEncoding); overload;
```

Сериализует документ и сохраняет результат в файл с указанной кодировкой. При необходимости записывает BOM (preamble) кодировки. При ошибке открытия или записи файла возбуждает `ESCLWritingException`.

```pascal
class procedure WriteFile(const AFileName: string;
  Document: TSCLDocument; Encoding: TEncoding);
```

Удобный статический метод: создаёт экземпляр `TSCLWriter`, сохраняет документ в файл и автоматически освобождает писатель.

### Поведение и особенности

- **Строки**:
  - `stDefault` — экранируются двойными кавычками с использованием escape-последовательностей (`\n`, `\t`, `\r`, `\f`, `\b`, `\xNN` и т.п.);
  - `stLiteral` — записываются в одинарных кавычках; одиночные кавычки внутри удваиваются; непечатные символы и переносы строк недопустимы (возбуждается исключение);
  - `stText` — записываются как блочный литерал `|` с сохранением переносов строк и добавлением отступа; при наличии завершающего перевода строки или ведущего пробела автоматически добавляются модификаторы (`+`, числовой отступ);
  - `stWrapped` — записываются как свёрнутый блок `>` с переносом длинных строк по пробелам вблизи `WrapWidth` (с учётом `WRAP_BIAS`); переносы строк в исходном тексте сохраняются как границы абзацев.
- **Комментарии узлов** записываются перед узлом в виде строк `# ...`; многострочные комментарии разбиваются построчно.
- **Массивы и таблицы**:
  - пустые или строчные (`IsInline`) контейнеры пишутся в одну строку: `[]`, `{}`, а также `[a, b]`, `{k1: v1; k2: v2}`;
  - блочные контейнеры пишутся с отступами; для элементов массивов используется префикс `- `;
  - при `LeadArray = False` первый элемент вложенного в массив контейнера пишется с текущей строки (после `- `), при `LeadArray = True` — с новой строки с дополнительным отступом.
- **Разделители**: в строчных массивах — `, `, в строчных таблицах — `; `.
- **Проверка символов**: при записи строк, текстовых блоков и свёрнутых блоков проверяется допустимость символов через внутреннюю таблицу `StringMap`; непечатные символы приводят к возбуждению `ESCLWritingException`.
- **Ширина переноса**: для свёрнутых блоков эффективная ширина вычисляется как `Max(WrapWidth - Indent, MIN_WRAPPED_WIDTH)`, где `Indent` — отступ содержимого блока с учётом текущего уровня вложенности.
- **Файловый вывод**: файл открывается с флагом `fmShareExclusive`; при наличии BOM у кодировки он записывается в начало файла.
